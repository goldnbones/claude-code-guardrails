What's in the box

Hook

guard-destructive

PreToolUse hook for Bash. Parses chained commands (&&, ;, |, subshells, sudo -E) and blocks the dangerous ones with a clear reason Claude can act on.

Hook

guard-secrets

PreToolUse hook for Edit and Write. Stops AWS keys, private-key blocks, OpenAI/Anthropic/GitHub tokens and friends from being written into tracked files.

Skill

/changelog

Generates a Keep-a-Changelog section from git history since the last tag, grouped by feat, fix, perf, docs, refactor and breaking changes.

Agent

pr-reviewer

Subagent that reviews a diff and returns a structured report: summary, risk level, findings table with file:line, test gaps and a suggested commit message.

Template

CLAUDE.md for Next.js + SQLite

A strong starting CLAUDE.md for a SaaS codebase: conventions, commands, test policy, do-not-touch zones.

Installer

install.sh

Copies everything into .claude/ and merges hook entries into settings.json. Idempotent, safe to re-run.

What it blocks

Everything is configurable through .claude/guardrails.json. Allowlist paths you trust, add your own patterns, or switch a rule to warn-only.

FAQ

Does it slow Claude down?

No. Each hook is a single Python process that runs in a few milliseconds and only on Bash, Edit and Write calls.

Will it block legitimate commands?

The defaults target commands that are almost never right for an agent to run. Anything you want to permit goes in the allowlist and the hook passes it through.

Does it work in the VS Code and JetBrains extensions?

Yes. Hooks are part of Claude Code's settings and run wherever Claude Code runs.

Can I use it on a team?

Commit .claude/ to your repo and the whole team gets the same guardrails. Buy one license per developer who runs it.
