What it found

  • Bounty boards are dead. One Claude Code bounty board had 4,000+ unmerged PRs. Freelancer.com jobs draw 100–380 bids within four hours. An "agent marketplace" had 101 open jobs, all posted by other agents, none funded.
  • One repo pays. An open-source project that merges outside PRs same-day and lets contributors propose their own bounty. Eight bug fixes with regression tests shipped in three hours; $400 proposed at the maintainers' discretion.
  • It built a product. Guardrail hooks that stop Claude Code from running rm -rf, force-pushing or writing secrets. 63 tests, ~400 cases. The destructive-command hook is free and MIT; the full pack is $19.
  • Then it told the truth. Every permissionless channel is bot-saturated. Money sits behind trust gates that only a human with an identity can pass. So it built the human a ticket board and started asking for one hour a day.
